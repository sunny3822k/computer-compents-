# Hardware Forge

An interactive PC hardware learning page built with React, Vite, Tailwind CSS, and Lucide icons.

## Run locally

Install Node.js (which includes npm), then from this folder run:

```sh
npm install
npm run dev
```

Open the local URL printed by Vite. To create a production build, run `npm run build`.

## Learning features

- Four progressive levels, from hardware intuition to build mastery
- Kitchen and technical explanations for seven PC components
- Component selection, build sequence, data flow, and bottleneck examples
- Interactive knowledge check and expandable form-factor reference
- Responsive layout, reading progress, and image fallbacks

Component and hero photography is loaded from Unsplash; all instructional content and interactions work independently of those images.
